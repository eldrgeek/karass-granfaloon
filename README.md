# karass-granfaloon

A one-question page for five people who shared a table at AGI-26 (Scott Wolfson,
Kes Sampanthar, Elana Yonah, Todd Bezenek, Mike Wolf): are we a Vonnegut *karass*
(a team bound by real, if invisible, purpose) or a *granfaloon* (a false one —
same badge, same room, no shared destiny)?

- **Live:** https://karass-granfaloon.netlify.app
- Static site, no build step. Responses captured via Netlify Forms (`karass-response`) —
  no backend, no database.
- `private/contacts-research.md` (gitignored) holds background on the four people,
  pulled from Mike's own email/contacts — never committed, never public.

First rev built by Mike Wolf + Claude (Sonnet 5), 2026-07-30. Mike is adding more
context on the four people for a v2.
